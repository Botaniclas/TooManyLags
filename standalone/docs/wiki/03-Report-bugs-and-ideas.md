# Report bugs and ideas

Real-world testing is still limited. Please share bugs and ideas through [GitHub Issues](https://github.com/Botaniclas/TooManyLags/issues).

Before reporting a bug, test on a separate copy of your host/server and world:

1. Run only Valheim and BepInEx, without this mod or other mods. Repeat the steps that caused the problem. If it still happens, please report it to the relevant project rather than here.
2. Add only TooManyLags - Standalone and repeat the same steps. If the problem appears only with this mod, open an issue with a detailed description, steps to reproduce, mod versions, relevant settings and logs. Mention whether the session is locally hosted or dedicated and which clients have the mod installed.

Thanks for helping improve the mod. Have fun, and enjoy smoother adventures together!
