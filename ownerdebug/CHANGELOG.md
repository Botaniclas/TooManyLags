# Changelog

**1.0.12**
```
- Replaces F10 mode cycling with a settings menu, six independent category switches and an immediately updated radius. Category switches start off; the old broad filter settings are no longer used.
- Adds optional TooManyLags ai_test phase colours: ordinary owner colours before/after transfer, red for fake playback and orange for final smoothing. Active handoffs colour the native mob draw and restore original material slots after rendering; no extra geometry or CPU skinning is used.
- Assigns purple, green, blue and yellow randomly without repetition to the first four players, with stable colours for the connection. Prepares the overlay after final camera pose callbacks and clears stale camera passes.
```

**1.0.11**
```
- Adds destructible world objects and physical network roots to All objects and mobs, including standing trees, rocks, ore and fallen logs. Live movement and ownership colours use the existing overlay; effects and player visuals remain excluded.
```

**1.0.10**
```
- Includes dropped items in the interactive-object and All overlays, with live ownership colours and pickup cleanup. Mobs only still hides them; carried item visuals and effects remain excluded.
```
